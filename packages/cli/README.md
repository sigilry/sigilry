# @sigilry/cli

TypeScript code generation from DAML DARs for Canton Network applications, including applications using Sigilry's CIP-0103 dApp SDK.

## Install

```bash
yarn add --dev @sigilry/cli@^0.3
```

The CLI has its own 0.x version line. Wallet connectivity uses `@sigilry/dapp@^3` and, for React, `@sigilry/react@^3`.

## Usage

See the [CLI guide](https://sigilry.org/packages/cli/) for `sigilry.config.ts`, DAR inputs, `dpm` prerequisites, and code generation commands.
