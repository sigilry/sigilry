## WindowTransport

`WindowTransport` uses `window.postMessage` for cross-context communication.

<Snippet path="concepts/window-transport.ts" />

### Options

- `timeout`: request timeout in milliseconds (default `30000`).
- `targetOrigin`: `postMessage` target origin (default `*`).
- `target`: optional routing key that addresses one wallet extension when several are installed (default unset). Providers from [discovery](../discovery/) set it from the wallet's announcement.

## WalletConnectTransport

`WalletConnectTransport` carries the same JSON-RPC surface over the WalletConnect relay instead of `postMessage`, for WalletConnect-capable Canton wallets (cross-device, no extension). It requires a WalletConnect Cloud `projectId` and dApp `metadata`; see the [API reference](../../api-reference/dapp/src/classes/walletconnecttransport/) for the full `WalletConnectTransportConfig`.
