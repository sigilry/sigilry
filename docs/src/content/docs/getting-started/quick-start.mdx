This guide shows two paths:

- **Vanilla**: Use `window.canton` directly with `@sigilry/dapp`.
- **React**: Use hooks from `@sigilry/react`.

## Before you start

- Node.js 18+ and Yarn installed.
- A Sigilry-compatible wallet extension available in your browser.
- For React apps: `@tanstack/react-query`.

For a hosted wallet, follow [Connect to Send Connect testnet](/guides/send-connect-testnet/). For a local wallet simulator, run the demo:

```bash
nix develop
yarn install
yarn --cwd examples/demo-app dev
```

## 1. Install packages

Vanilla:

```bash
yarn add @sigilry/dapp@^3
```

React:

```bash
yarn add @sigilry/react@^3 @sigilry/dapp@^3 @tanstack/react-query
```

The stable dapp/react line is 3.x on `latest`; the old `next` prerelease tag is frozen. See [Migrations](/migrations/) when upgrading from 1.x or 2.x.

## 2. Verify the provider is available

```ts
if (!window.canton) {
  throw new Error("Canton provider not available");
}
```

## 6. What success looks like

- Calling `status` returns a typed payload (no provider/runtime schema errors).
- Connect action completes and `listAccounts` returns at least one account.
- In React, the connect button transitions to a connected account view.

## 7. Common first-run issues

- `Canton provider not available`: wallet extension not installed/active on this page.
- Connect appears to do nothing: check extension permission prompts and site access settings.
- Empty accounts after connect: wallet may not have an active account on the current network.

## 8. Next steps

- Learn the protocol in [RPC Protocol](../../concepts/rpc-protocol/).
- Explore package docs: [@sigilry/dapp](../../packages/dapp/), [@sigilry/react](../../packages/react/), [@sigilry/cli](../../packages/cli/), [@sigilry/splice-dars](../../packages/splice-dars/).
- Generate TypeScript types from Splice DARs: install `@sigilry/splice-dars` and `@sigilry/cli`, then run `sigilry codegen`.
