---
title: API Reference
description: Where to find the generated TypeScript API reference and the OpenRPC schema.
---

The [generated API reference](../api-reference/readme/) is built from the TSDoc in each package's
entry point and lists every exported class, function, interface, and type alias.

The CIP-103 OpenRPC schema that the `@sigilry/dapp` Zod schemas are generated from is vendored at
`packages/dapp/api-specs/openrpc-dapp-api.json`. See [CIP-103 Conformance](../concepts/cip-103-conformance/)
for how it maps to the provider surface.

For usage-oriented documentation, start with the package guides:

- [@sigilry/dapp](../packages/dapp/)
- [@sigilry/react](../packages/react/)
- [@sigilry/cli](../packages/cli/)
- [@sigilry/splice-dars](../packages/splice-dars/)
